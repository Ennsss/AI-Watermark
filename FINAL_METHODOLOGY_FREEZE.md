## 1. Research comparison and watermark configuration

The final comparison changes only the bit-decision mechanism. Each branch
receives the same attacked image, preprocessing, two-level Haar DWT, LH2/HL2
subbands, seed-42 locations, coefficient values, 128-bit payload, and delta 24.
Classical extraction applies the analytical binary-QIM decision; neural
extraction applies the frozen seed-aware CNN decision.

- Input before embedding: 512×512 RGB uint8
- Processing: RGB → YCbCr; embed/extract from Y
- DWT: Haar, level 2, production symmetric boundary mode
- Subbands and locations: 64 LH2 + 64 HL2, deterministic seed 42
- Payload: 128 bits
- Embedding: binary QIM, delta **24**, frozen after Stage 3A
- ECC, extra redundancy, and synchronization correction: none

Production embedding/extraction behavior is unchanged by this freeze.

## 2. Final primary CNN and checkpoint

Checkpoint: `experiments/stage3a_delta_calibration/delta_24/best_seed_aware_delta24.keras`

Size: 35,321 bytes

SHA-256: `afae879e3078543d3be030889b277a90245c3c73b041b912a209b1489729e53d`

For each selected coefficient `c`, the input is `c/24`,
`sin(pi*c/24)`, `cos(pi*c/24)`, and subband ID (`LH2=0`, `HL2=1`).
Input shape is `(None, 128, 4)`. The verified architecture is:

1. Conv1D(16, kernel size 1, ReLU)
2. Conv1D(16, kernel size 1, ReLU)
3. Conv1D(1, kernel size 1, sigmoid)

It has 369 parameters and threshold 0.5. It has no pooling, global dense layer,
cross-payload interaction, coordinates, attack labels, clean reference,
classical decisions, or classical confidence.

The Stage 4B 601-parameter 3×3 resize-aware decoder remains a development
ablation only. It modestly improved Resize75/50 but did not meaningfully recover
Resize25, used a more specialized representation, and failed its primary severe
resize hypothesis. Retaining the 369-parameter decoder preserves the clearest
classical-versus-learned decision comparison.

## 4. Frozen 13-condition suite

1. Clean
2. JPEG Q90
3. JPEG Q70
4. JPEG Q50
5. Resize75
6. Resize50
7. Resize25
8. Mild crop
9. Moderate crop
10. Severe crop
11. Reencode1
12. Reencode2
13. Reencode3

JPEG uses OpenCV: RGB→BGR, `cv2.imencode('.jpg', ..., IMWRITE_JPEG_QUALITY)`,
`cv2.imdecode(..., IMREAD_COLOR)`, then BGR→RGB. Repeated JPEG re-encoding uses
the same Q85 encode/decode cycle sequentially one, two, or three times.

Resize converts RGB→BGR, downsamples with `cv2.INTER_AREA`, restores the
original 512×512 dimensions with `cv2.INTER_LANCZOS4`, then returns BGR→RGB:
512→384→512, 512→256→512, and 512→128→512.

Crop calls `crop_severity` and `random_crop`, then uses NumPy slicing without
restoration or interpolation. Ranges are mild 5–10%, moderate 20–30%, and
severe 40–50%. Seed 0 is reset for each image-condition call. The severity
ratio is drawn first; `random_crop` restarts seed 0 and draws top, bottom, left,
right in that order. Thus geometry is deterministic and, because all inputs are
512×512, does not vary between images for a given severity. The configured
ratio is a range parameter; independent edge draws determine actual removed
area.

For every image/condition, embedding occurs once and the attack is generated
once. The exact attacked ndarray is shared by classical and CNN extraction;
random crop is never regenerated separately per branch.

## 6. Frozen outcomes and diagnostics

Primary outcome is per-image/condition/decoder BER: incorrect bits divided by
128. Per condition, report mean, median, population standard deviation, minimum,
maximum, and perfect recovery count/rate. Perfect means all 128 bits correct.
The primary aggregate is macro-average BER over the 12 attacked conditions;
clean is separate. An all-condition macro may be supplementary.

Secondary diagnostics are classical/CNN LH2 and HL2 BER and, for CNN,
target-one frequency, predicted-one frequency, false-zero count, and false-one
count. No ECC-derived success measure is permitted.

Embedding imperceptibility compares original against clean watermarked full-RGB
uint8 images, using the Stage 3A implementation: PSNR `data_range=255` and SSIM
`data_range=255, channel_axis=-1`. Attacked-versus-original fidelity is not the
primary watermark imperceptibility measurement.

## 7. Computational benchmark

All classical and CNN measurements use one designated machine: B550M-HVS SE,
AMD Ryzen 7 5700G (8 cores/16 logical processors), 33,687,789,568 bytes RAM,
Windows 11 build 26200. Frozen environment versions are Python 3.13.7,
TensorFlow 2.21.0, NumPy 2.5.0, PyWavelets 1.8.0, OpenCV 4.13.0,
scikit-image 0.26.0, and SciPy 1.18.0. Native Windows TensorFlow runs on CPU;
GPU timing is excluded. Thread-count environment variables were unset at freeze.

Timing uses `perf_counter_ns` and `process_time_ns`, three CNN warm-ups, three
recorded repetitions, identical sample order, and median time. End-to-end starts
when the attacked image enters extraction and includes color conversion, DWT,
location regeneration, gathering, and decision through 128 output bits.
Decision-only starts with gathered coefficients (classical) or the corresponding
featurized coefficients (CNN) and ends with 128 decisions. Peak Python allocation
uses `tracemalloc`. Normalized CPU utilization is
`100 * process CPU time / (wall time * 16)`.

## 8. Frozen statistical analysis

The experimental unit is one image/payload condition instance, never an
individual bit. For each of the 12 attack conditions, compare paired per-image
CNN and classical BER with `scipy.stats.wilcoxon`, `alternative='two-sided'`,
`zero_method='wilcox'`, and `method='auto'`. All-zero paired differences return
the predefined neutral p-value 1.0. Record the runtime SciPy version.

Apply Holm adjustment at alpha 0.05 across the 12 raw attack-condition p-values;
report raw and adjusted values. Clean is descriptive rather than part of this
family. Also report an aggregate Wilcoxon comparison on each image's mean BER
across the 12 attacks.

Rank-biserial correlation is
`(W_positive-W_negative)/(W_positive+W_negative)`, using average ranks for tied
absolute nonzero differences and excluding zeros. Differences are
`classical BER - CNN BER`, so positive effect indicates lower CNN BER. Always
report the mean paired BER difference, relative reduction where defined, and
counts for CNN better/equal/worse.

## 9. Interpretation fixed before testing

JPEG and repeated JPEG are primarily coefficient-value degradation. Resize75/50
measure learned response to resampling. Resize25 is a known severe development
limitation and may not trigger tuning. Crop development failure was dominated by
shape-dependent coefficient-permutation synchronization loss; near-random crop
BER must not be presented as proof of intrinsic CNN bit-classification inability.
